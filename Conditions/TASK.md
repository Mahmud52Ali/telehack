# Разработка модуля сбора данных о СКЗИ

## Исходные данные:

- Файлы открытой части сертификатов
- Структура базы данных таблицы в БД
- Директории для сканирования

## Общие требования к инструментам разработки и программному обеспечению:

- Язык программирования C# NET Framework 4.5
- База данных MSSQL
- Проект должен быть скомпилирован в бинарный файл под операционную систему Windows 10 и иметь расширение «.exe»
- Программа должна иметь систему логирования, в файл с логами должна записываться информация о некорректной работе программы, все «exceptions» должны вписывать в файл с логами, у каждого лога должна указывать дата и время в точности до миллисекунд. Пример, оформления файла с логами:

## Описание функционала программного обеспечения

Программное обеспечение должно осуществлять сбор данных обо всех личных сертификатах, установленных на сканируемом ПК, а также данные о версии Крипто Про установленной на сканируемом ПК, совершать парсинг сертификатов, после чего полученные в ходе парсинга данные помещать в таблицу в БД. ПО должно иметь панель управления, через которую пользователь ПО будет осуществлять сканирование указанных им ПК в локальной сети

## Поэтапное выполнение задания:

1. Создание функционала для чтения конфигурационного файла, в котором будут указаны директории для сканирования.
2. Разработка функций сканирования директорий и парсинга файлов в данных директориях
3. Разработать функционал для сканирования указанных ПК и сбора данных с запущенного на них сканирования.
4. Разработать функционал отправки данных в таблицу БД. Данный функционал должен учитывать существование таблицы в БД в которую должны быть помещены данные, если таблицы нет, то ПО должно произвести ее создание и только после этого внести данные, если таблица уже существовала, то нужно просто внести в нее полученные данные.

### 4.1. Данные которые необходимо внести в таблицу:

- Серийный номер сертификата
- Дата и время внесения в таблицу
- Дата и время обновления данных в таблице (если вносится не первый раз, если первый, то равно дате и времени внесения)
- Имя владельца
- Удостоверяющий центр
- Если это лицензия Крипто Про, то указать версию
- Встроена ли лицензия Крипто Про в сертификат

**4.2.** При внесении данных в таблицу нужно реализовать проверку на наличие данного сертификата в таблице, если сертификат с таким серийным номером уже существует, то строку нужно просто обновить и актуализировать данные в столбце «Дата и время обновления» ни в коем случае не добавляя вторую строку с таким же сертификатом, так как это будет являться дублированием данных.

## Требования к оформлению исходного кода программы:

1) Код программы должен быть хорошо комментирован, достаточно указывать комментарии у функции с указанием действия, которое выполняет данная функция (комментировать каждую строку не обязательно).
2) В коде должны быть осмысленные имена у переменных, классов и функций, имена должны явно указывать на то, что хранит в себе переменная или какое действие выполняет функция.
3) В коде между операторами и операндами обязательно ставиться пробелы. Пример: `sum = a + b` вместо `sum=a+b`. Это правило касается и условных операторов.
4) Использовать табуляцию для дочерних блоков кода.

Пример кода с табуляцией:

```java
// Сортирует список
public static void sortIntList(ArrayList<Integer> list){
	for(int i = 0; i < list.size() - 1; i++){
		int index_min = i;
		for(int j = i + 1; j < list.size(); j++){
			if(list.get(j) < list.get(index_min)){
				index_min = j;
			}
		}
		int temp_num = list.get(i);
		list.set(i, list.get(index_min));
		list.set(index_min, temp_num);
	}
}
```

Пример кода без табуляции:

